# Privacy Policy

This plugin sends chat requests from your Dify instance directly to the UnoRouter API (`https://api.unorouter.com`). The following data leaves your Dify instance when you use it:

- The prompt messages, model parameters, and tool definitions of each request you run
- Your UnoRouter API key, used as a Bearer token to authenticate those requests

The plugin stores nothing itself. It keeps no logs, sends no telemetry, and contacts no endpoint other than the UnoRouter API.

How UnoRouter processes requests is described in its privacy policy: https://unorouter.com/privacy

The plugin source is open: https://github.com/0-don/dify-unorouter
